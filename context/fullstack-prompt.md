## Anti-Patterns — NEVER Do These

- [NEVER define the same type separately on frontend and backend
  — share it from a single source]
- [NEVER trust client-side auth checks alone — always verify
  on the server]
- [NEVER skip server-side validation because the client already
  validates]
- [NEVER return raw database records to the client — map to DTOs]
- [NEVER hardcode API URLs in components — use environment
  variables or a centralized API client]
- [NEVER mix UI logic and data fetching logic in the same
  component — separate into hooks]
- [NEVER modify the database schema without updating shared types
  and running a migration]
- [NEVER modify files in [protected directories from
  ai-workflow-rules.md]]
