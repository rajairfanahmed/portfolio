# UX floor

Always on. Every frontend level. Brutalist and WebGL included.

- Paginate or virtualize every long list
- Empty, loading, and error states on every data view
- Toasts or inline errors for failed actions
- Keyboard path and visible focus
- Touch targets at least 44px
- WCAG 2.2 AA contrast unless the user waives it in `03-your-product/ui-context.md`
- Forms: validate, block double submit, show success
- Do not invent a second token set. Use `03-your-product/ui-context.md` only
